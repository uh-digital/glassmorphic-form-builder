# ✨ Dynamic Glassmorphic Form Builder

A modern, highly interactive frontend workspace tool that allows users to design customized UI forms dynamically. Built with a sleek cybersecurity dark-theme aesthetic, it features real-time backdrop blur configurations and fluid top-center state validation toast alerts.

## 🛠️ Key Features
- **Dynamic Field Injection:** Add and remove Text inputs, Password elements, and Dropdown selection blocks seamlessly on the fly.
- **Interactive State Validation:** Prevents form code export if workspace is blank or if text fields are left empty, displaying custom Red Error Toasts.
- **Live Styling Control:** Integrated adjustment slider to modify CSS background blur levels instantly.
- **Automated Clipboard Export:** One-click code copying with top-center Green Success Toast confirmations.

## 💻 Tech Stack
- **HTML5:** Semantic workspace layout and structured elements.
- **Tailwind CSS:** Premium gradient backgrounds, responsive grid layouts, and advanced glassmorphism utility classes.
- **Vanilla JavaScript:** DOM node creation, state tracking arrays, asynchronous Clipboard API management, and custom toast animation timers.

## 🚀 How to Run Locally
1. Clone this repository to your local machine.
2. Launch the `index.html` file using your web browser or via the VS Code **Live Server** extension.
